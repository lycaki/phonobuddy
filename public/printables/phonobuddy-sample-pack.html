How to use this pack

Use one short page at a time. Five calm minutes is better than a long session that becomes hard work.

1. Say the sound

Point to one card. Say the pure sound, then ask the child to repeat it.

2. Find it

Ask the child to find the same grapheme in a word ladder or sentence.

3. Blend it

Touch each sound from left to right, then sweep across and read the word.

4. Keep it light

Stop while it is still going well. Put a tick in the tracker and come back tomorrow.
